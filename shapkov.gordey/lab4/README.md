# Лабораторная работа 4

## Задание

Вариант 26. Реализовать класс Library с методами добавления и удаления книг, а
также 5 функций для работы с коллекцией библиотек (группировка по жанру/году,
уникальные авторы/годы, поиск по автору). Реализовать пользовательский интерфейс
с асинхронным добавлением/удалением (через setTimeout) и сохранением состояния в
localStorage.

## Реализация

- **Модель (`model.js`)**: Экспортирует класс `Library` и 5 чистых функций для
  агрегации данных. Использованы `Map`, `Set` и методы массивов (`filter`,
  `reduce`) для избежания мутации исходных данных.
- **Интерфейс (`main.js`)**: Использует делегирование событий для удаления.
  Добавление и удаление обернуты в `Promise` с `setTimeout` для имитации
  асинхронности. Состояние синхронизируется с `localStorage` при каждом
  изменении.
- **DOM-контракт**: Строго соблюдены селекторы `[data-testid="entity-list"]`,
  `[data-testid="entity-form"]`, `[data-testid="entity-card"]`,
  `[data-testid="delete-entity"]`. Поля формы имеют атрибуты `name`,
  соответствующие полям модели.

## Запуск

Откройте `index.html` в браузере.
